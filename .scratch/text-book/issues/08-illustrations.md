# 08: 插圖

**What to build:** md 裡 `![替代文字](路徑)` 引用的本地圖片成為**插圖**，打包進書並顯示在原位置：

- 支援 JPEG、PNG、GIF、WebP（副檔名不分大小寫）；路徑以 md 檔所在資料夾為基準，可以指向輸入資料夾以外的檔案。
- 多個章引用同一個來源檔時只打包一份。沒被引用的圖片不打包、不警告。
- 重用漫畫書的圖片處理：WebP 預設轉 JPEG（`--keep-webp` 保留）、`--quality`、`--max-size` 規則相同。
- 找不到或損毀的插圖預設報錯，訊息指出是哪一張並提示 `--skip-broken`；加上 `--skip-broken` 時輸出替代文字，並把它列在結束時的跳過清單。
- 網路圖片（有 scheme 的 URL）、SVG、其他不支援格式：不打包，輸出替代文字並產生警告。
- 替代文字為空時，以檔名作為替代文字。

涵蓋 spec 的 user story 5、37–47。

## Comments

- 2026-11-22：工作分配。
  - 轉譯函式自己處理網路圖片（有 scheme）與不支援的副檔名（SVG、TIFF、沒有副檔名），改顯示替代文字並警告，不交給解析器。
  - 只有 JPEG、PNG、GIF、WebP 的本地路徑交給解析器。
  - 解析器回傳 None 代表被 `--skip-broken` 跳過，已經記在跳過清單裡，所以改顯示替代文字時不再另外警告。
- `links.py` 改名為 `targets.py`（`BookTargets` / `ChapterTargets`），因為同一個解析器同時處理連結與插圖。插圖的載入、去重複、跳過放在 `illustrations.py`。
- 插圖在書中的路徑是 `OEBPS/images/illus-NNNN.<副檔名>`，依第一次被引用的順序編號。副檔名取處理後的格式，例如 WebP 轉 JPEG 後是 `.jpg`。
- 替代文字為空時，只在「改顯示替代文字」的情況以檔名替代。成功打包的圖片 `alt` 維持空字串，代表裝飾用圖片。
- 跳過清單的名稱是「引用它的 md：路徑」。同一張壞圖被多章引用時只列一次，列的是第一個引用它的章。
- 審查記下但未處理：
  - 路徑帶 `?query` 或 `#片段` 時判斷不出副檔名，會被當成不支援的格式。
  - 漫畫書與插圖各有一份「跳過損毀圖片」的處理，訊息與記錄方式不同。
  - 既有問題（漫畫書也一樣）：副檔名與實際內容不符時（例如 `.jpg` 其實是 PNG），media type 依副檔名決定。
