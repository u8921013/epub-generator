# 08: 插圖

**What to build:** md 裡 `![替代文字](路徑)` 引用的本地圖片成為**插圖**，打包進書並顯示在原位置：

- 支援 JPEG、PNG、GIF、WebP（副檔名不分大小寫）；路徑以 md 檔所在資料夾為基準，可以指向輸入資料夾以外的檔案。
- 多個章引用同一個來源檔時只打包一份。沒被引用的圖片不打包、不警告。
- 重用漫畫書的圖片處理：WebP 預設轉 JPEG（`--keep-webp` 保留）、`--quality`、`--max-size` 規則相同。
- 找不到或損毀的插圖預設報錯，訊息指出是哪一張並提示 `--skip-broken`；加上 `--skip-broken` 時輸出替代文字，並把它列在結束時的跳過清單。
- 網路圖片（有 scheme 的 URL）、SVG、其他不支援格式：不打包，輸出替代文字並產生警告。
- 替代文字為空時，以檔名作為替代文字。

涵蓋 spec 的 user story 5、37–47。

**Blocked by:** 05（警告機制）

**Status:** ready-for-agent

- [ ] 被引用的本地插圖打包進書、在 manifest 中，章 XHTML 在原位置引用它
- [ ] 子資料夾中的 md 以自己的位置為基準解析相對路徑
- [ ] 輸入資料夾以外的插圖可用
- [ ] 同一來源被多章引用時只打包一份
- [ ] 沒被引用的圖片不在書裡
- [ ] `--keep-webp`、`--quality`、`--max-size` 對插圖生效，規則與漫畫書相同
- [ ] 缺少或損毀的插圖：預設錯誤（結束代碼 1、不留輸出檔、訊息提示 `--skip-broken`）
- [ ] `--skip-broken`：輸出替代文字，結束時列出被跳過的插圖，結束代碼 0
- [ ] 網路圖片、SVG 輸出替代文字並產生警告，書中沒有它們
- [ ] 替代文字為空時以檔名替代
- [ ] EPUB 解析輔助工具能列出打包的插圖
- [ ] EPUBCheck 情境表加入「有插圖」的文字書，沒有錯誤
