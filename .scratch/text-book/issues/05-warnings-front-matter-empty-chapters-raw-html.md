# 05: 警告機制、front matter、空章、原始 HTML

**What to build:** 建立文字書的警告機制：轉換過程中產生的警告在結束時集中列在標準錯誤，每一項包含檔名與原因；有警告但成功時結束代碼為 0。並用它處理三種情況：

- 檔案開頭的 YAML front matter（`---` 單獨一行開頭、到對應的 `---` 結束）整段略過，不出現在書裡、不當作書籍資訊。
- 略過 front matter 後沒有任何內容的 md 跳過並警告，不產生空白章；整個資料夾沒有任何有內容的章時報錯（結束代碼 1）。
- md 裡的原始 HTML（區塊與行內）轉義成純文字顯示，並對該檔案產生警告。

建書結果新增警告清單；CLI 負責把它印出。

涵蓋 spec 的 user story 27–30、59、60。

**Blocked by:** 02（最簡單的文字書）

**Status:** ready-for-agent

- [ ] 警告在結束時集中列在標準錯誤，每項有檔名與原因；有警告時結束代碼仍為 0
- [ ] 沒有警告時標準錯誤不多出任何文字
- [ ] front matter 被略過，內文從其後開始
- [ ] 開頭的 `---` 沒有對應結束行時，不當作 front matter（照一般 Markdown 處理）
- [ ] 空檔案與只有 front matter 的檔案被跳過並警告，章數與目錄不含它們
- [ ] 全部都是空章時報錯，訊息說明沒有可用內容，不留下輸出檔
- [ ] 原始 HTML 區塊與行內 HTML 都轉義成可見的純文字，並產生警告
- [ ] 第二接縫：front matter 略過、只有 front matter 回報為空、原始 HTML 轉義與警告都有測試
- [ ] 輸出仍是格式正確的 XHTML，EPUBCheck 沒有錯誤
