# 02: 最簡單的文字書：根目錄的 md 檔轉成 reflowable EPUB

**What to build:** 使用者執行 `epubgen ./pages`，`pages` 是一個只在根目錄放了 Markdown 檔的資料夾，就會在旁邊得到 `pages.epub`：一本可重排的 EPUB 3 **文字書**。每個 md 檔是一**章**，章依檔名自然排序（`8096_2` 在 `8096_10` 前），**章名**取檔案內第一個一級標題，沒有時取去掉副檔名的檔名（保留數字前綴）。目錄一層，每章一個項目，指向該章開頭。完成時標準輸出印出輸出路徑與「共 N 章」。

書的種類依 ADR 0001 自動判斷：資料夾任何位置有 `.md` / `.markdown`（不分大小寫）就是文字書，否則照舊產生**漫畫書**。

這張票同時建立兩個測試接縫：

- 主接縫沿用 CLI 進入點；EPUB 解析輔助工具擴充出「讀出某章文字 / XHTML」與「讀出目錄」的觀察方法。
- 第二接縫：Markdown 轉譯的純函式，最小版本只需處理一般段落、標題與 CommonMark 基本行內格式，並回傳章名。目標解析介面先定好形狀即可（連結與插圖在 07、08 實作）。

新增 `markdown-it-py` 執行期依賴。reflowable 組裝與現有 fixed layout 組裝共用 container、metadata、zip 打包等共通部分。

做完這張，使用者手上那本 234 章的小說資料夾就能轉換。

涵蓋 spec 的 user story 1–4、6–13、18、48、49、54、56、58、61–64、67、68。
