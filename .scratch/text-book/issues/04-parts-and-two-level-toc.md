# 04: 部與兩層目錄

**What to build:** 使用者把 md 放進第一層子資料夾時，每個子資料夾成為一**部**，部名是資料夾名稱。根目錄的章排在所有部之前、不屬於任何部；部依名稱自然排序；更深層子資料夾裡的 md 依相對路徑自然排序併入所屬的第一層部。閱讀器的目錄變成兩層：部是第一層項目並指向該部第一章，章是第二層項目。只放圖片、沒有任何 md 的子資料夾不成為部。

涵蓋 spec 的 user story 14–17、19–21。

**Blocked by:** 02（最簡單的文字書）

**Status:** ready-for-agent

- [ ] 第一層子資料夾成為部，部名為資料夾名稱
- [ ] 根目錄的章在所有部之前，於目錄中為第一層項目
- [ ] 部依資料夾名稱自然排序（`第2部` 在 `第10部` 前）
- [ ] 更深層的 md 併入所屬第一層部，依相對路徑自然排序
- [ ] 目錄兩層：部指向其第一章，章為部底下的第二層項目
- [ ] 沒有 md 的子資料夾不出現在目錄
- [ ] 章 XHTML 依整本書的閱讀順序排列在 spine 中
- [ ] EPUB 解析輔助工具能讀出兩層目錄（名稱、層級、目標章）
- [ ] EPUBCheck 情境表加入「有部有章」的文字書，沒有錯誤
