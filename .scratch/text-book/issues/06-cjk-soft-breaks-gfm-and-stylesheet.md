# 06: 中文軟換行、表格、刪除線、程式碼區塊與內建樣式

**What to build:** 讓文字書的內容在閱讀器上呈現得像一本正常的書：

- 段落裡的單一換行，前後兩個字元都是中日韓文字或全形標點時直接相連，不插入空白；其他情況（例如英文）照標準輸出空白。
- 啟用表格與刪除線，並正確呈現 CommonMark 的引用、清單、分隔線、程式碼區塊（保留縮排與換行，等寬字，不做語法上色）。
- 加入一份內建 CSS：段落間距、標題、程式碼區塊、表格框線、圖片最大寬度 100%。不嵌入字型，不強制字型家族，讓閱讀器設定生效。

實作前要明確列出「中日韓文字與全形標點」所用的 Unicode 區段，並在測試中涵蓋邊界。

涵蓋 spec 的 user story 22–26、65。

**Blocked by:** 02（最簡單的文字書）

**Status:** ready-for-agent

- [ ] 第二接縫：`今天天氣很好，\n我們去散步。` 轉成相連的文字，中間沒有空白
- [ ] 第二接縫：英文的軟換行轉成空白；中英交界依規則處理，並有測試
- [ ] 第二接縫：表格、刪除線、程式碼區塊、引用、清單、分隔線的輸出正確且為格式正確的 XHTML
- [ ] 程式碼區塊中的換行與縮排保留，不受軟換行規則影響
- [ ] 每章 XHTML 都引用內建 CSS，CSS 在 manifest 中
- [ ] EPUB 中沒有嵌入任何字型
- [ ] EPUBCheck 情境表加入「含表格與程式碼區塊」的文字書，沒有錯誤
