# 06: 中文軟換行、表格、刪除線、程式碼區塊與內建樣式

**What to build:** 讓文字書的內容在閱讀器上呈現得像一本正常的書：

- 段落裡的單一換行，前後兩個字元都是中日韓文字或全形標點時直接相連，不插入空白；其他情況（例如英文）照標準輸出空白。
- 啟用表格與刪除線，並正確呈現 CommonMark 的引用、清單、分隔線、程式碼區塊（保留縮排與換行，等寬字，不做語法上色）。
- 加入一份內建 CSS：段落間距、標題、程式碼區塊、表格框線、圖片最大寬度 100%。不嵌入字型，不強制字型家族，讓閱讀器設定生效。

實作前要明確列出「中日韓文字與全形標點」所用的 Unicode 區段，並在測試中涵蓋邊界。

涵蓋 spec 的 user story 22–26、65。

## Comments

- 2026-11-22：中日韓區段依 CSS Text Level 3 的分段換行規則，完整清單已寫進 spec「轉譯規則」的軟換行一條；測試逐一涵蓋各區段的邊界字元。
- 刻意的取捨：韓文不算（以空白分詞，相連會黏詞），已寫入 spec。
- Spec 審查指出中文小說常用的 `“”‘’…—·` 屬中西文共用的標點、不在區段內，會造成「中文⏎“引號”」多出空白。改為越過這些標點看同段文字的下一個字元決定，中文語境相連、英文語境保留空白；同時補上小寫變體、假名補充、帶圈表意文字補充。
- 軟換行旁是圖片或行內 HTML 時保留空白；判斷會跳過粗體、連結、行內程式碼的格式標記。標題（目錄文字）也套用同一規則。
- 內建 CSS 放在 `OEBPS/styles/book.css`，只有 `pre`、`code` 指定等寬字型家族，其餘交給閱讀器。
