# 04: 書籍資訊與指定封面

**What to build:** 使用者可以用參數覆寫書名、指定作者、指定語言，以及指定第一張圖以外的圖片當封面，讓書櫃裡的書名、作者與縮圖都正確。參數名稱由實作者決定，spec 的建議名稱是 `--title`、`--author`、`--language`、`--cover`。

spec 沒有明確決定的細節，採用它建議的做法：

- 書名含有檔名不允許的字元時，預設輸出檔名替換掉這些字元，但 metadata 裡的書名保留原樣。
- 封面參數接受輸入資料夾內外的任何圖片。若該圖片本來就在頁面中，不重複加入 EPUB。

涵蓋 spec 的 user story 21、23–25。

**Blocked by:** 01

**Status:** resolved

- [x] 書名參數會寫入 metadata，且預設輸出檔名改為 `<書名>.epub`
- [x] 書名含檔名不允許的字元時，輸出檔名中這些字元被替換，metadata 的書名不變
- [x] 作者參數會寫入 metadata；沒給時 metadata 不含作者
- [x] 語言參數會寫入 metadata；沒給時是 `zh-TW`
- [x] 封面參數指定頁面中的某張圖時，該圖被標記為 cover image，且在 EPUB 中只出現一次
- [x] 封面參數指定輸入資料夾外的圖片時，該圖被加入 EPUB 並標記為 cover image，頁面內容與順序不變
- [x] 封面參數指向不存在或無法讀取的檔案時，報錯並以非零結束代碼結束
- [x] `--help` 顯示這些參數與預設值
- [x] 以上行為都有透過 CLI 進入點的測試
