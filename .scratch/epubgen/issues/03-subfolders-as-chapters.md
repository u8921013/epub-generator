# 03: 子資料夾變成章節目錄

**What to build:** 輸入資料夾有子資料夾時，每個第一層子資料夾成為一章。章節依子資料夾名稱自然排序（「第 2 話」在「第 10 話」前），章節名稱就是子資料夾名稱，閱讀器的目錄可以直接跳到各章第一頁。章節內的頁面同樣依檔名自然排序。

spec 沒有明確決定的兩個情況，採用它建議的做法：

- 根目錄與子資料夾同時有圖片時，根目錄的圖片排在最前面，不屬於任何章節。
- 有多層子資料夾時，只把第一層當章節，更深層的圖片併入所屬的第一層章節，並依路徑自然排序。

涵蓋 spec 的 user story 15–18。
