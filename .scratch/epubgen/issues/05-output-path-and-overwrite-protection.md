# 05: 輸出路徑與覆蓋保護

**What to build:** 使用者可以用 `-o` 把 EPUB 直接輸出到指定路徑（例如同步資料夾或閱讀器的掛載點）。輸出檔已經存在時，工具預設拒絕覆蓋並報錯；加上 `--force` 才會覆蓋。輸出先寫到暫存檔，成功後才移到目標路徑，所以任何失敗都不會留下半成品。整個過程不修改輸入資料夾。

涵蓋 spec 的 user story 32、34、39–41。

**Blocked by:** 01

**Status:** resolved

- [x] `-o <路徑>` 把 EPUB 寫到該路徑，成功訊息顯示的是該路徑
- [x] 輸出檔已存在且沒有 `--force` 時：錯誤訊息寫到標準錯誤輸出、非零結束代碼、既有檔案內容不變
- [x] 輸出檔已存在且有 `--force` 時：覆蓋成功，結束代碼為 0
- [x] 轉換中途失敗時，目標路徑沒有新檔案，也沒有殘留的暫存檔

- [x] `--help` 顯示 `-o` 與 `--force`
- [x] 以上行為都有透過 CLI 進入點的測試
