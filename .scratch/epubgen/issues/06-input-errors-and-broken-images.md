# 06: 輸入錯誤與損毀圖片處理

**What to build:** 使用者給錯輸入時，會看到清楚的錯誤訊息，而且工具以非零結束代碼結束、不產生輸出檔，方便在腳本裡批次處理並判斷成敗。涵蓋的情況：輸入路徑不存在或不是資料夾、資料夾裡沒有任何圖片、圖片損毀、參數值不合法。

圖片損毀時預設報錯並指出是哪個檔案。加上 `--skip-broken` 則跳過損毀的圖片繼續產生 EPUB，並在結束時列出被跳過的檔名。如果所有圖片都被跳過，視同沒有圖片而報錯。

錯誤訊息一律寫到標準錯誤輸出。

涵蓋 spec 的 user story 35–38、42，以及 41 中與這些錯誤相關的部分。

**Blocked by:** 01

**Status:** ready-for-agent

- [x] 輸入路徑不存在：錯誤訊息指出路徑，非零結束代碼
- [x] 輸入路徑是檔案而不是資料夾：錯誤訊息說明原因，非零結束代碼
- [x] 資料夾裡沒有任何可用圖片（空資料夾或只有非圖片檔案）：報錯，非零結束代碼，不產生空書
- [x] 有損毀圖片且沒有 `--skip-broken`：錯誤訊息指出損毀的檔名，非零結束代碼
- [x] 有損毀圖片且有 `--skip-broken`：EPUB 產生成功，不含損毀的圖片，頁數等於可用圖片數，並列出被跳過的檔名
- [x] 所有圖片都損毀且有 `--skip-broken`：報錯，非零結束代碼
- [x] 不合法的參數值（例如 `--direction up`，若票 02 尚未完成則用其他參數驗證）：顯示用法說明，非零結束代碼
- [x] 以上所有失敗情況都不留下輸出檔
- [x] 錯誤訊息出現在標準錯誤輸出，不出現在標準輸出
- [x] 以上行為都有透過 CLI 進入點的測試
