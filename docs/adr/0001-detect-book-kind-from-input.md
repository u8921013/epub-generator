# 依輸入資料夾內容判斷書的種類

`epubgen` 原本只產生漫畫書；加入文字書時，我們決定不新增子指令或切換旗標，而是看輸入資料夾：任何位置有 `.md` 檔就產生文字書，否則產生漫畫書。這樣既有的 `epubgen <資料夾>` 用法完全不變，使用者也不必記兩種指令。代價是判斷規則成為 CLI 契約的一部分，日後若要支援第三種輸入，需要沿用或擴充這套判斷，而不是另開子指令。

## Considered Options

- **子指令**（`epubgen comic <dir>` / `epubgen text <dir>`）：最明確，但會破壞現有用法。
- **切換旗標**（`epubgen --text <dir>`）：不破壞現有用法，但使用者每次都要多打一個旗標，而資料夾內容本身已經足以判斷。

## Consequences

- 文字書資料夾裡的圖片一律視為插圖候選，不會被當成漫畫頁。
- 只對漫畫書有意義的旗標（`--direction`、`--spread`）用在文字書時要報錯，而不是默默忽略。
